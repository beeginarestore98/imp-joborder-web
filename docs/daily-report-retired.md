# Daily LINE report removed

Removed at owner's request on 2026-10-21 to keep the OA interaction reply-driven. The web report menu, route and component are removed. Supabase report settings and recipient switches are disabled; queued/retry deliveries are cancelled; cron jobs impjo-evening-report-1700 and impjo-report-delivery are unscheduled. The public impjo_reports(uuid,text,jsonb) RPC now rejects all operations with FEATURE_REMOVED so older browser clients cannot re-enable delivery. Existing report storage is retained for compatibility with job/account deletion cleanup; no job, user, status or audit data is removed. Disabled settings also prevent legacy claim/destination functions from providing work to the deployed worker. No secrets or OA access tokens are changed; live chat replies and Rich Menu continue to use the existing Reply API. TypeScript and Vite production build pass.

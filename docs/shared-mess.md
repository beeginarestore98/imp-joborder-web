# MESS รายงานผลร่วมกัน

เงื่อนไขล่าสุดจากเจ้าของระบบ: MESS ที่ ADMIN อนุมัติและบัญชียังเปิดใช้งาน ทุกคนรายงานผล B/L ที่กำลังดำเนินการได้ โดยไม่ต้องมอบหมายรายคน ใช้ได้ทั้งเว็บและ LINE คำสั่ง MESS → Contact Name → B/L → เสร็จสมบูรณ์ / แจ้งปัญหา → ยืนยันบันทึก

รายละเอียดปัญหายังคงจำเป็น Audit Log เก็บ principal ผู้กระทำจริง การเปลี่ยนสถานะล็อกแถวและตรวจสถานะปัจจุบันเพื่อป้องกันการรายงานทับงานที่เสร็จแล้ว ผู้ใช้รออนุมัติหรือปิดใช้งานไม่มีสิทธิ์ MESS เปิดงานที่เสร็จแล้วกลับเองไม่ได้ OPERATOR / OUTSOURCE ใช้กติกาปรับทุกสถานะที่อนุมัติก่อนหน้า

ตัวเลือกมอบหมาย MESS ถูกนำออกจากเว็บ ประวัติการมอบหมายเก่าเก็บไว้ การมอบหมาย OUTSOURCE ยังใช้สำหรับขอบเขตการแก้ไขงานเดิม ไม่ต้องเพิ่ม environment variables หรือ secret ใหม่

ใช้ shared-mess-reporting.sql หลัง flexible-status.sql ทดสอบ tests/shared-mess.sql กับฐานข้อมูลจริงโดย rollback fixtures ทั้งหมด ตรวจ capability ทั้งเว็บและ chat, MESS สองคนที่ไม่เคยได้รับ assignment, actor audit, required issue detail, pending/disabled denial และป้องกันการเปลี่ยนงานที่เสร็จแล้วซ้ำ

เอกสารนี้แทนข้อความเรื่อง MESS ต้องได้รับมอบหมายในเอกสารและชุดทดสอบ SQL รุ่นเก่า ฐานข้อมูลจริงใช้สิทธิ์แบบร่วมกันตาม migration นี้
